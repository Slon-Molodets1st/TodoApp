# TodoApp


Полноценное приложение для управления задачами с бэкендом на **Python (FastAPI)** и фронтендом на **TypeScript (React)**.

## Возможности

- Создание задач
- Просмотр списка задач
- Отметка о выполнении задач
- Удаление задач
- Автоматическая документация API (Swagger UI)
- Тесты для бэкенда (Pytest)
- Современный интерфейс на React + TypeScript

## Технологии

**Бэкенд:**
- [FastAPI](https://fastapi.tiangolo.com/) — современный веб-фреймворк
- [SQLAlchemy](https://www.sqlalchemy.org/) — ORM для работы с БД
- [Pydantic](https://docs.pydantic.dev/) — валидация данных
- [Uvicorn](https://www.uvicorn.org/) — ASGI сервер

**Фронтенд:**
- [React](https://react.dev/) — библиотека для UI
- [TypeScript](https://www.typescriptlang.org/) — типизированный JavaScript
- [Axios](https://axios-http.com/) — HTTP клиент

**Тестирование:**
- [Pytest](https://pytest.org/) — тестирование бэкенда
